## What I explored

This project focuses on a complete game loop in one browser file: input, paddle movement, ball collision, scoring, menus, difficulty, and restart behavior.

## Tech stack

<ul class="tech-list"><li>HTML</li><li>CSS</li><li>JavaScript</li><li>Canvas 2D</li><li>Game AI</li></ul>

## Reflection

The single-file format made the prototype fast to build and easy to share. A next step would separate rendering and game state, then add touch controls for phones.
